

We are rebuilding Fixly.work from a static service website into a React / Next.js hybrid platform:

Main goal:
SEO service website + home services lead marketplace.

Current setup

Project created from scratch:

pnpm create next-app@latest fixly-web --typescript --eslint --app --src-dir --import-alias "@/*" --no-tailwind

Using:

pnpm dev -p 4081

Local URL:

http://localhost:4081

package.json should use:

"dev": "next dev -p 4081"

Marketplace concept

Fixly should become:

SEO website with service pages.
Request/lead marketplace.
Public job/request pages visible to everyone.
Only registered pros can respond to jobs.
SEO pages should link into the marketplace.
Marketplace may not need to link heavily back to SEO pages.
